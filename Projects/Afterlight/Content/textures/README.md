Rain Court uses constant linear PBR parameters and procedural floor seams.

Honeybud contains 24 authored 1024×1024 Texture assets: base color, normal and ORM for eight surfaces. Leaf veins, porcelain insets/gilt, cushion stitches and grass detail use these maps instead of dense geometry. PNG companions are provided for DCC inspection. The `.asset` files contain TEX1 RGBA8 payloads and are referenced by reusable Material assets. See `docs/honeybud-art-pipeline.md` at the repository root.
