# Constraint Lab — 动态编译执行图的通用 GPU Dynamics

ConstraintLab 展示 Whimsical 的通用 GPU Dynamics 方案：通过 JavaScript 声明数学空间、变量、残差、等式 / 不等式条件和持久状态更新，在运行时将模型编译为 GPU 求解执行图，异步执行并消费结果。

## 从数学定义到 GPU 执行

1. **定义模型**：使用欧氏空间、旋转空间或自定义空间，描述变量与关系。关系可以包含多行残差和等式 / 不等式条件，求解乘子由系统管理。
2. **编译执行图**：自动生成 Jacobian，建立数据布局与依赖，安排 Colored / Jacobi / Hybrid 求解阶段。符合容量条件的静态区域会融合到工作组，在共享内存中执行子步与迭代；大型区域与动态端点模型保留全局执行路径。
3. **运行时修改**：数值补丁更新参数、柔顺度、逆度量和启用状态；拓扑变更后重新编译并迁移保留状态。声明为动态的端点可在固定容量内逐步更新连接，无需每次重新编译。
4. **提交与消费结果**：异步提交求解、轮询完成状态，按需回读或发布 GPU 状态，获取耗时与数值诊断。

数学接口、生命周期与代码示例见 [GPU Dynamics](../../docs/dynamics.md)，执行区域分析与融合见 [编译器说明](../../docs/dynamics-compiler-optimization.md)。修改本项目的 `Content/scripts/model.js` 可以定义自己的模型；当前界面提供示例参数操作，公式由脚本编写。

## 当前演示：绳索与碰撞

绳索是这套方案的一个交互示例。每条绳子使用 64 个 R3 变量；距离、球面 / 半空间碰撞以及位移阻尼都由项目表达式定义，经同一编译器生成求解计划。

双击本目录的 `Run.cmd` 启动（需要先构建 `build/bin/Release/Whimsical.exe`）。

## 示例操作

- `I`：推一下绳子，观察侧向摆动。
- `C`：松开 / 接回右端，观察绳子滑过球面并落地。
- 方向键：移动固定的右端；界面的 `− / +` 调整端点高度。
- `W`：自动前后摆动右端。
- `Space`：暂停 / 继续；暂停后 `N` 或「单步」推进一次。
- `R`：恢复初始悬挂状态。
- 中键拖动：旋转视角；滚轮：缩放。
- 距离柔顺度：切换柔软 / 适中 / 紧致。
- `Hybrid / Jacobi`：切换求解策略并重置。
- 1 / 16 / 64 条：同时求解并显示对应数量的独立绳子，按 1 × 1 / 4 × 4 / 8 × 8 网格排列，镜头自动调整。端点、扰动和柔顺度控制作用于全部绳子。

## 示例实现

- `Content/scripts/model.js`：定义 R3 空间、距离关系、球面 / 半空间不等式，以及使用关系历史的位移阻尼；构建数据批次，通过异步提交 / 轮询驱动求解。
- `Content/scripts/view.js`：把每条绳子各自的 GPU 位置回读转换成绳段，在独立局部坐标系对应的展台上显示。渲染插值不参与物理求解。
- `Content/scripts/main.js`：UI 与控制。
- `Content/UI/`：中文操作面板、求解耗时和诊断信息。
- `tools/generate_meshes.py`：生成项目自有的 STM1 圆柱 / 球体网格和绳子材质。

每次求解推进 1/30 秒，4 子步 × 12 迭代。模拟通过异步任务推进；繁重负载下模拟时间可慢于墙钟时间。每次回读全部绳子的节点位置：1 / 16 / 64 条分别为 768 字节 / 12 KiB / 48 KiB。界面的长度误差统计所有绳子的已完成 GPU 样本。静态展台合并成项目自有网格；64 条绳子合计 960 个渲染实例，在引擎现有上限内。多绳总览中，每条绳子使用 12 个可视绳段降低绘制开销，物理求解始终保留每条 64 个节点；每个可视绳段都取自对应绳子的真实结果。

当前演示只定义了距离约束绳索，尚未定义弯曲 / 扭转和自碰撞关系。通用求解器的能力由空间、关系与编译执行契约描述，示例中的具体几何和物理模型由项目提供。

## 构建与运行

```powershell
.\third_party\cmake\bin\cmake.exe --build build --config Release --target Whimsical -j 6
.\Projects\ConstraintLab\Run.cmd
```

有限帧截图：`Run.cmd --capture --frames 240`，输出到仓库 `captures/frame.bmp`。加 `--validation` 可启用 Vulkan validation。
