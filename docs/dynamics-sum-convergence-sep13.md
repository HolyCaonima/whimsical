# 集合求和的线性求解与显示统计修正（2026-09-13）

1 万粒子的示例曾在落地后持续发散。修正保留用户定义的自由度、关系公式、参数、初值、1/30 秒 tick 和 Hybrid / 4 子步 / 12 次外迭代，只改变编译器生成的线性求解过程以及项目中的显示统计。

## 原因与修改

显示统计原来每次遍历全部 10,000 × 10,000 配对，虽然设置了 2 ms 截止时间，却每处理 8 个完整锚点才检查一次。实际 Duktape 单次调用占用 35–36 ms。现在对不可变快照分帧建立哈希索引，均匀取 256 个锚点，每个锚点仍累计完整邻域的原密度多项式。索引构建和链表遍历内部每 64 个工作单元检查时间。实测 48 个调用完成一次统计，每个调用最多 2 ms，总 CPU 时间约 95 ms。面板明确标注“采样”。此索引完全不参与物理求解。

求解器原来在每次非线性线性化后，只执行一轮按活动邻接度缩小的块 Jacobi 更新。密集耦合关系的修正收敛很慢，落地时严重挤压，墙角会出现完全重合的状态；紧支撑多项式的导数退化后，局部 Newton 修正可变得极大。NaN / 奇异计数为零并不意味着稳定。原编译器同样复现此问题：第 180 步最高位置约 21,450；并行优化初版的复现为 11,038–17,276。因此初版的短程有限值检查不足以证明收敛。

当前编译器物化有界稀疏 Jacobian J、加权 Jacobian W、局部矩阵 A、线性化右端项 b 和该快照的乘子 λ₀。在一次非线性快照内执行四轮线性求解：

    Aᵢ = Jᵢ M⁻¹ Jᵢᵀ + αᵢ
    bᵢ = −Cᵢ − αᵢ λ₀ᵢ
    rᵢ = bᵢ − Jᵢ Δq − αᵢ(λᵢ − λ₀ᵢ)
    λᵢ ← project(λᵢ + relaxation · Aᵢ⁻¹ rᵢ / degreeᵢ)
    Δq ← Δq + Wᵢ Δλᵢ

α 是原 compliance / h²。各轮使用累计切空间位移 Δq，重新计算耦合线性残差，不重复加入同一个原始修正。第四轮后才通过原 Gather / retract 更新真实状态。下一次外迭代重新索引和线性化。额外工作只读取缓存和乘子，不重复执行邻域查询、公式求值或自动微分。

求解与散射均采用 32 lanes / 关系行，散射按实际成员数循环。低维稀疏记录包含通用自由度 ID、slot、J 和 W。编译器没有任何具体物理对象类别、速度裁剪、位置上限、额外碰撞关系或材料常数。

## 执行边界

- 仅在原有 Auto、活动权重、有限支撑证明、成员映射单射与资源预算满足时启用缓存求解。共享线性化预算仍为 8 KiB；SumData 总预算增至 64 MiB，10,000 行的线性化记录约 41.5 MB。
- 投影、compliance 和块求解继续复用原实现；多行块、切空间映射和非对角 inverseMetric 保留其原有含义。线性迭代改变有限预算下的数值轨迹，不能视为逐位等价变换。
- 列表溢出、不可索引或不能物化的行仍执行完整流式求和一次。额外线性轮次跳过这些行，不能重复散射旧修正；同一快照内它们的累计贡献可被缓存行读取。
- 多个缓存域按原域顺序执行块更新。其余 Jacobi 关系保留原路径。这里只细化缓存块的线性求解，并未声称一次精确求解整个模型。
- 每轮先求解再散射，保留跨工作组依赖。奇异或非有限块先清空瞬时输出，避免沿用上一轮 Δλ。乘子基值在每次线性化时重写。
- Model、Adapter、Runtime、RenderCore 和用户 DSL 接口未修改。对照驱动与当前示例 define / build 段的 SHA-256 相同，详见汇总数据。

## 验证结果

Release / RTX 3080 / Vulkan validation，10,000 个自由度，完整原始模型，持续 1,800 tick，即 60 秒模拟时间。全量位置、速度回读，并用原密度公式在 CPU 上复核全部 10,000 个锚点的邻域。

| tick | 最高位置 Y | 速度 RMS | 平均密度超限 |
| ---: | ---: | ---: | ---: |
| 30 | 3.568 | 1.2473 | 0.790% |
| 180 | 0.592 | 0.05444 | 0.724% |
| 720 | 0.560 | 0.00482 | 0.723% |
| 1,800 | 0.560 | 0.000762 | 0.724% |

最终最高速度约 0.022，密度超限 P99 为 3.36%，最大为 10.97%。运动已经衰减，有限预算下仍有约束残差，不能将它描述成所有关系残差收敛到零。全过程 invalid / singular 为 0，Vulkan validation 无错误。

完整 GPU 提交时间：tick 31–180 平均 40.97 ms，最后 180 tick 平均 48.71 ms；该区间包括提交内同步及传输，不是纯算术计时。稳定后的密集邻域持续存在，不能拿粒子大量逃逸后的低耗时宣称提速。作为收敛成本排查，直接增加到 96 次非线性外迭代也可稳定，但会重复昂贵的索引和 AD；该排查配置没有写入项目。

已有 dynamics_solver、dynamics_sum_dsl 均通过，未新增或修改测试。Whimsical 重编译后实际运行 900 渲染帧，界面显示 10,000 个粒子和采样密度，水体保持在容器内，正常退出，validation errors=0。截帧显示 tick 755、模拟时间 25.17 秒。
